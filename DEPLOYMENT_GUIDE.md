# Deployment Guide for Gupta Classes Premium Coaching Website

## 1. Overview
- Brief description of the Gupta Classes premium coaching website.

## 2. Prerequisites
- Git installed on your local machine.
- A GitHub account.
- Basic knowledge of HTML, CSS, and JavaScript.

## 3. Cloning the Repository
- Use the following command to clone the repository:
  ```
  git clone https://github.com/Kartikopp/guptaclasses.git
  ```

## 4. Configuring Files for GitHub Pages
- Ensure that the main HTML file is named `index.html`.
- Place all CSS files in a `css` directory and JavaScript files in a `js` directory. 
- Ensure all links to CSS and JavaScript files in `index.html` use relative paths.

## 5. Committing Changes
- Add and commit your changes with the following commands:
  ```bash
  git add .
  git commit -m "Prepare website for GitHub Pages deployment"
  ```

## 6. Pushing Changes
- Push changes to the `main` branch:
  ```bash
  git push origin main
  ```

## 7. Publishing on GitHub Pages
- Go to the repository settings on GitHub.
- Scroll to the "GitHub Pages" section.
- Select the `main` branch and click "Save".

## 8. Accessing the Website
- Your website will be available at: `https://Kartikopp.github.io/guptaclasses`
